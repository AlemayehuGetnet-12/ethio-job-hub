# Ethio Career Connect

Capstone Project: Ethiopian Job Marketplace Platform Project Title EthioJobs Connect – A Modern Ethiopian Job Marketplace Project Overview The goal of this capstone project is to build a complete job marketplace that connects Ethiopian job seekers with employers through a modern web platform. Students will apply everything they have learned throughout the course, including frontend development, backend development, database design, authentication, authorization, API development, deployment, and third-party integrations. The platform should allow employers to post jobs, manage applications, and hire candidates, while job seekers can create professional profiles, search for jobs, and apply online. Students will also build one additional client:  Mobile Application (React Native or Flutter) OR  Telegram Bot / Telegram Mini App The additional client should communicate with the same backend API. Learning Objectives After completing this project students should be able to:  Design a real-world database  Build REST APIs  Implement JWT Authentication  Build Role-Based Access Control  Upload files  Handle search and filtering  Build responsive UI  Deploy frontend and backend  Integrate third-party services  Consume APIs from multiple clients  Build scalable software architecture Technology Stack Frontend  Next.js  React  TypeScript (optional)  Tailwind CSS  Redux Toolkit or Context API  Axios  React Hook Form  Zod/Yup Validation Backend  Node.js  Express.js  MongoDB  Mongoose  JWT Authentication  Bcrypt  Multer  Cloudinary  Nodemailer Database MongoDB Collections:  Users  Companies  Jobs  Applications  Categories  Skills  Notifications  SavedJobs  Reviews  Messages User Roles 1.
